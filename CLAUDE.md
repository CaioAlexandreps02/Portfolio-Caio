# Portfólio Caio Porto

Site de portfólio profissional. Next.js + Supabase + Tailwind.

## Contexto

Caio Porto — profissional de Marketing com atuação em design gráfico, vídeo,
social media, sistemas e desenvolvimento de sites.

**Finalidades:**
- Conseguir clientes freelance
- Impressionar em processos seletivos (CLT)
- Mostrar trabalho para parceiros e empresas

## Stack

- Next.js (App Router)
- Supabase (PostgreSQL + Auth)
- Tailwind CSS
- Deploy: Vercel

## Regras

- TODO UI em português do Brasil
- Dark mode e Light mode com toggle
- Modo admin é o MESMO site público — login ativa controles de edição inline
- Nunca commitar sem aprovação explícita do Caio
- Zero erros TypeScript antes de concluir qualquer tarefa
